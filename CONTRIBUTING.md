# Contributing to Hacktoberfest Meetup Phagwara 💙

Welcome to the Hacktoberfest Meetup Phagwara repository! 🎉

We're excited to have you here. Whether this is your first open-source contribution or you're an experienced developer, you're welcome to contribute.

As part of our community, you can add your profile to our **Attendee Wall** and become part of the event's contributor showcase!

Your first pull request starts here. 🚀

## 🌟 How Can You Contribute?

You can participate by adding your attendee profile to our repository.

Each contributor adds one JSON file containing their name and GitHub username. Once your pull request is reviewed and merged, your profile can appear on our website.

## 🛠️ Getting Started

### Step 1: Fork This Repository

Visit the repository:

[Hacktoberfest Meetup Phagwara](https://github.com/shashankpandey04/hacktoberfest-meetup-phagwara)

Click the **Fork** button in the top-right corner to create your own copy.

### Step 2: Clone Your Fork

Open your terminal and run:

```bash
git clone https://github.com/YOUR-GITHUB-USERNAME/hacktoberfest-meetup-phagwara.git
cd hacktoberfest-meetup-phagwara
```

Replace `YOUR-GITHUB-USERNAME` with your GitHub username.

### Step 3: Create Your Profile

Navigate to:

```text
app/attendees/
```

Create a new JSON file named after your GitHub username.

For example, if your GitHub username is `octocat`, create:

```text
app/attendees/octocat.json
```

**Important:** Use your actual GitHub username as the filename. Do not modify or overwrite another contributor's profile.

### Step 4: Add Your Information

Add the following information to your JSON file:

```json
{
  "fullName": "Your Full Name",
  "githubUsername": "YOUR-GITHUB-USERNAME",
  "pfpUrl": "https://github.com/YOUR-GITHUB-USERNAME.png"
}
```

Replace the placeholder values with your own information.

**Field descriptions:**

| Field | Description |
|---|---|
| `fullName` | Your full name |
| `githubUsername` | Your exact GitHub username |
| `pfpUrl` | Your GitHub profile picture URL |

**A few rules:**
- Use valid JSON syntax and double quotes.
- Ensure your filename matches your GitHub username.
- Use your actual GitHub username and a publicly accessible profile picture.
- Do not include passwords, access tokens, or other sensitive information.
- Submit only your own profile.

### Step 5: Commit Your Changes

Save your file and run:

```bash
git add app/attendees/YOUR-GITHUB-USERNAME.json
git commit -m "Add YOUR-GITHUB-USERNAME to attendee wall"
git push origin main
```

Replace `YOUR-GITHUB-USERNAME` with your actual GitHub username.

If your fork uses a different default branch, replace `main` with that branch's name.

### Step 6: Open a Pull Request

Visit your fork on GitHub.

Click **Compare & pull request** and submit your changes to the original repository:

`shashankpandey04/hacktoberfest-meetup-phagwara`

Use a descriptive title, such as:

```text
Add YOUR-GITHUB-USERNAME to attendee wall
```

In the description, briefly explain that you've added your attendee profile.

Submit your pull request and wait for the organizers to review it.

### Step 7: Get Featured! 🎉

Once your pull request is reviewed and merged, your profile can be included in the website's attendee showcase.

Welcome to the community of builders!

## 📋 Contribution Guidelines

To keep the repository organized, please follow these guidelines:

1. **One profile per contributor:** Add only your own profile.
2. **Unique filenames:** Your filename must use your GitHub username and end in `.json`.
3. **Valid JSON:** Ensure your file follows the required structure.
4. **No duplicate profiles:** Check whether your profile already exists before submitting.
5. **No unrelated changes:** Keep your pull request focused on your attendee profile.
6. **Respect others:** Do not modify or delete another contributor's profile.
7. **Accurate information:** Submit genuine information associated with your own GitHub account.

Pull requests that do not follow these guidelines may require changes before they can be merged.
